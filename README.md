# Data 498 Course Toolkit — Spring 2026

A shared collection of data science references, examples, and reusable code snippets developed for Data 498 during Spring 2026.

## Purpose

This repository brings course resources into one searchable place and provides a foundation that can continue to grow after the class. Materials may include practical examples, reference notes, small utilities, and links that support data analysis work.

## Contributing

Add resources in a clearly named folder and include enough context for another student to understand when and how to use them. Keep examples concise, document required packages or data, and avoid committing credentials, private course records, or generated cache files.
